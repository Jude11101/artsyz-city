# 🏛️ Город Арциз - Официальный сайт

Профессиональный туристический сайт о городе Арциз, Одесская область, Украина.

## 📋 Содержание

- **Главная страница** - Приветственный баннер с описанием города
- **О городе** - Информация о населении, истории и статистике
- **Достопримечательности** - 6 основных мест для посещения
- **История** - Временная шкала развития города
- **Контакты** - Информация для связи и форма обратной связи

## 🎨 Особенности

✅ Современный профессиональный дизайн
✅ Полностью на русском языке
✅ Адаптивный для всех устройств (мобильный, планшет, десктоп)
✅ Плавная навигация и прокрутка
✅ Красивые анимации при наведении
✅ Быстрая загрузка

## 🚀 Как использовать

1. Откройте `index.html` в браузере
2. Или разверните на GitHub Pages:
   - Перейдите в Settings репозитория
   - Выберите "Pages" в боковом меню
   - Выберите "main" branch
   - Сайт будет доступен по ссылке

## 📁 Файлы

- `index.html` - Основная структура
- `styles.css` - Стили и дизайн
- `script.js` - Интерактивность
